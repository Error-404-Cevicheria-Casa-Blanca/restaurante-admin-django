1. Objetivo y Criterios de Aceptación

Integrar el módulo de catálogo de la rama feature/PE-19-catalogo-platos en develop y resolver de forma limpia la convivencia entre SQLite local y PostgreSQL central para modelos con managed=False, garantizando que el entorno local arranque en limpio con SQLite sin requerir base de datos externa.

Criterio de Aceptación Oficial: develop arranca en limpio con SQLite y el catálogo es 100% operable.

2. Solución Arquitectónica: Convivencia SQLite y PostgreSQL (Regla D7)

En entornos compartidos de arquitectura distribuida (Spring Boot + Django + PostgreSQL central), la base de datos PostgreSQL no debe ser alterada por el ORM de Django (managed = False en los modelos de dominio). Sin embargo, para desarrollo local ágil y ejecución de pruebas automatizadas sin dependencias externas, se implementó el cargador dinámico catalogo/sqlite_bootstrap.py:

  • Detección Automática de Motor: Si no se detectan variables de entorno de PostgreSQL (DB_NAME, DB_USER, etc.), Django conmuta automáticamente a sqlite3 local (db.sqlite3).
  • Cargador DDL Virtual para SQLite: sqlite_bootstrap.py inicializa dinámicamente las tablas de dominio (categoria, producto, mesa, usuario, rol) con sus restricciones y datos semilla iniciales solo cuando se ejecuta en SQLite.
  • Preservación de Regla D7: En PostgreSQL, Django no genera migraciones DDL sobre las tablas de negocio, manteniendo el script db/schema.sql como la única fuente de verdad.

3. Procedimiento de Arranque Local en Limpio

# 1. Clonar el repositorio y ubicarse en la rama develop
git clone https://github.com/Error-404-Cevicheria-Casa-Blanca/restaurante-admin-django.git
cd restaurante-admin-django
git checkout develop

# 2. Crear y activar entorno virtual Python
python -m venv venv
.\venv\Scripts\activate

# 3. Instalar dependencias
pip install -r requirements.txt
pip install -r requirements-dev.txt

# 4. Arranque Local 100% Offline con SQLite (Zero-Config)
python manage.py runserver 127.0.0.1:8000

# 5. Arranque conectado a PostgreSQL (Opcional, usando script automatizado)
.\iniciar_servidor.bat
